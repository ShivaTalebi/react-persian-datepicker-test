# Flexible Persian Datepicker Demo

دموی آنلاین و پروژهٔ تست پکیج `flexible-persian-datepicker`، شامل نمونه‌های
Input، Span، Input Group، فرمت‌های مختلف، فوتر اختیاری و بازه‌های غیرفعال.

این پروژه مستقل از دموی تقویم چندگانه است و نسخهٔ `1.3.3` پکیج منتشرشده در
npm را آزمایش می‌کند.

پس از ساخت repository با نام `react-persian-datepicker-test`، آدرس دمو:

`https://shivatalebi.github.io/react-persian-datepicker-test/`

## اجرای محلی

```bash
npm install
npm run dev
```

## خروجی production

```bash
npm run build
```

این پروژه با هر push روی شاخهٔ `main` از طریق GitHub Actions در GitHub Pages
منتشر می‌شود.
